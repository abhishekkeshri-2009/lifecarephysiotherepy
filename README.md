# Life Care Physiotherapy Center Website

Static-export Next.js website for `https://lifecarephysiotherepy.com`.

## Commands

- `npm run dev`
- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run build`

## Key files

- `src/config/business.ts`
- `src/content/services.ts`
- `src/content/conditions.ts`
- `src/content/faqs.ts`
- `src/content/blog.ts`
- `public/.htaccess`

## Launch note

Placeholders remain for email, address, maps, credentials, and analytics IDs. Review `BUSINESS-DATA-REQUIRED.md` before launch.
